# S.I.G.S.M. - Sistema Integral de Gestión de Servicios Médicos

## Descripción

El objetivo del proyecto es digitalizar y optimizar distintos procesos administrativos del Hospital de Clínicas mediante una plataforma modular, permitiendo la gestión centralizada de documentación institucional, categorías, encuestas y otros módulos administrativos que podrán incorporarse en futuras versiones.

## Objetivos

- Digitalizar procesos administrativos.
- Reducir el uso de documentación física.
- Facilitar el acceso a documentos institucionales.
- Mejorar la organización y gestión de la información.
- Proporcionar una plataforma escalable para futuros módulos del sistema.

## Convención de commits

Para mantener un historial de cambios ordenado y facilitar el seguimiento del desarrollo, el proyecto utiliza las siguientes convenciones para los mensajes de commit.

| Prefijo | Descripción | Ejemplo |
|----------|-------------|---------|
| **DOCS:** | Cambios en la documentación | `DOCS: actualiza README` |
| **CODE:** | Agregado o modificación general de código | `CODE: implementa login` |
| **FEAT:** | Nueva funcionalidad completada | `FEAT: completa módulo de documentos` |
| **FIX:** | Corrección de errores | `FIX: corrige validación de formulario` |
| **STYLE:** | Cambios visuales | `STYLE: mejora dashboard` |
| **REFACTOR:** | Reorganización del código sin cambiar su funcionamiento | `REFACTOR: reorganiza componentes` |
